# SEKAI token assets

Public metadata and logo for the SEKAI token on Solana. Wallets and explorers load them from here.

- Metadata: [`sekai.json`](sekai.json)
- Logo: [`logo/sekai-<size>.webp`](logo/sekai-512.webp), transparent, in 1024, 512, 256, 128, 64 and 32 px, plus PNG at 512 and 64 px
- Website: [`index.html`](index.html), a static page deployed on Vercel from this repo

SEKAI is an independent personal project, not affiliated with any company or app.
